# Stockwise — Inventory Decision Support System

Stockwise is a web-based Decision Support System (DSS) prototype developed to support inventory management and business decision-making.

The application provides an interactive dashboard designed to help users analyze inventory levels, identify potential stock shortages or overstock situations, visualize financial indicators, and explore demand forecasts.

### Main Features

- **Inventory Dashboard:** Visual overview of inventory information and key performance indicators.
- **ABC Analysis:** Classification of products based on their relative importance.
- **Stock Monitoring:** Identification of potential shortages and excess inventory.
- **Demand Forecasting:** Visualization of estimated future product demand.
- **Purchase Recommendations:** Suggested replenishment actions based on inventory indicators.
- **Scenario Simulation:** Interactive tools for exploring inventory-related decisions.

### Project Information

This project was developed as an academic demonstration of how Decision Support Systems can assist businesses in making more informed inventory management decisions.

**Note:** Stockwise is a functional frontend prototype intended for demonstration purposes. It does not require a backend database or permanent data storage.
